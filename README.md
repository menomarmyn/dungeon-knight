# Dungeon Knight: Rise of the Slime King

A mobile 2D action platformer made in **Unity 6.6 (6000.6.4f1)**. A tiny knight with a blaster runs and jumps through a pixel dungeon, shoots slimes and bats, collects energy crystals to open portals, and defeats the Slime King.

Game Development Fundamentals · weeks 9–13 project (grown from the midterm).

## Platform
- iOS / Android, **landscape**
- UI tested in Device Simulator: 16:9 phone, 19.5:9 notch phone, 4:3 tablet

## Controls
| On screen | Keyboard (debug) | Action |
|---|---|---|
| Joystick (bottom-left) | A / D, arrows | Run |
| Green button (bottom-right) | Space / W | Jump (hold = higher) |
| Red button (bottom-right) | X / J | Fire (hold = auto-fire) |
| II (top-right) | Esc / P | Pause: Resume · Restart · Menu |

## Screens
Main Menu → Level 1 → Level 2 → Boss → Win, plus the Pause menu.
All canvases: Canvas Scaler *Scale With Screen Size*, 1920 × 1080, Match = 1; HUD and buttons inside a `SafeArea` panel.

## How to open
1. Open the folder in Unity Hub with Unity 6000.6.4f1.
2. Menu **Midterm → Build Everything** (rebuilds scenes, prefabs, animators and the HUD).
3. Open `Assets/Scenes/Midterm/MainMenu.unity` and press Play.

## Project layout
- `Assets/Script` — game logic (player, enemies, boss, HUD, pause, score)
- `Assets/Midterm/Art`, `Audio`, `Fonts` — original pixel art, chiptune sounds, Press Start 2P font (OFL)
- `Assets/Midterm/Levels` — level layouts as text maps
- `Assets/Midterm/Editor/MidtermBuilder.cs` — editor tool that builds the scenes
- `GDD/Dungeon_Knight_GDD.pdf` — game design document

## Data and saves (week 11)
- **Balance in data assets** (`Assets/Midterm/Data`): `Player.asset`, `Slime.asset`, `Bat.asset`, `GoblinArcher.asset`, `SlimeKing.asset`, `Items.asset`, `Bullet/Arrow/Orb/Fireball.asset`. Scripts contain no balance numbers — change a value in the Inspector and the game changes.
- **Levels from data:** `Level_01/02/03.asset` (`LevelData`: title, map, crystals to open the portal, time limit, music, signs). One scene `Game` + `LevelLoader` builds any of them. Order: `Assets/Midterm/Resources/LevelCatalog.asset`.
- **Save:** `save.json` in `Application.persistentDataPath` (JsonUtility): unlocked and completed levels, best score, music and SFX volume. Missing or broken file → defaults, no crash. Saved after a level, when Settings closes and in `OnApplicationPause(true)`.
- **Menu:** level select with locked levels, best score, Settings → RESET PROGRESS with a confirm window.
- Windows: `save.json` is in `%USERPROFILE%\AppData\LocalLow\Student\Dungeon Knight\`.

## Sound (week 12)
- **AudioMixer** `Assets/Midterm/Resources/GameMix.mixer`: Master → Music (exposed `MusicVol`) → Tracks; Master → SFX (exposed `SFXVol`); Master → UI. Snapshots **Normal** and **Paused** (Tracks −6 dB + Lowpass Simple 800 Hz).
- **Music:** menu, level and boss tracks. One `MusicManager` (DontDestroyOnLoad) crossfades between them in 1 s; the same track keeps playing after Restart or Level 1 → Level 2.
- **Settings** in the main menu: Music and SFX sliders in dB (`Log10(v) × 20`), saved with PlayerPrefs, applied at launch.
- **Variation:** random pitch 0.92–1.08 on every repeated effect; hit, shoot, hurt and enemy death have 2–3 versions.
